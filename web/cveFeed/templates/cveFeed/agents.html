    Your agents

      No agent has registered on your tokens. An agent registers itself with register_agent, saying which hosts, projects or organizations it is responsible for and what it can do.

      Connect an agent

      Claude Code

      claude mcp add --transport http cvengine http://{{ host }}/mcp/ --header "Authorization: Bearer <token>"

      REST

      curl -H "Authorization: Bearer <token>" http://{{ host }}/api/v1/me

      Agents that take assigned work: register_agent once, then get_next_task, accept_task, report_task_result, with agent_heartbeat about once a minute. whoami shows your agent's scope and open assignments.

      Remediation agents that pick their own work: register_assets, then get_remediation_work, then update_remediation_status. The OpenAPI spec is at /api/v1/openapi.json.
