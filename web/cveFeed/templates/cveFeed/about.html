Sentinels: scale out scanning

Every scan runs on a Sentinel, a small scanner you run on any machine; none runs on the server. A Sentinel checks in with cvENGINE, takes work off the queue (port and service scans with nmap and naabu, nuclei, the testssl.sh TLS audit, WPScan, wafw00f, bbot discovery, Kingfisher secret detection, the sshamble SSH host key check, headless-Chromium screenshots, web, DNS and route probes, the hygiene checks, the UDP sweep and, where you turn it on, OpenVAS), runs it there and sends the results back. Deploy one or a hundred to spread scanning across machines. Deploy one inside a network cvENGINE cannot reach, such as an office or a cloud network, to scan the hosts there. The built-in scanner that every install starts is the last resort: it takes work only when no external Sentinel can. The client is open source at github.com/hevnsnt/cvengine-sentinel.
