Sentinels

A Sentinel is a scanner you run on your own network: it registers itself, pulls nmap, naabu and nuclei work off this project's queue, runs it and reports typed results back. This phase covers nmap, naabu and the nuclei passes; a scan with no live Sentinel runs those locally exactly as before.

Registered Sentinels

    No Sentinel has registered yet. Generate an enrollment secret for a project and give it to a Sentinel's setup.

    Enroll a Sentinel

    Needs the admin role in the project (or App Admin). The secret is single-use and expires in 30 minutes; the Sentinel trades it for its own token on its first call.

    What a Sentinel needs

    It is not a download yet in this release: point a client you run yourself at POST /api/v1/sentinels/bootstrap with the enrollment secret (body {enrollment_token, name}), store the token it returns, then loop sentinel/heartbeat and sentinel/tasks/next, accept, result. The OpenAPI spec is at /api/v1/openapi.json.
